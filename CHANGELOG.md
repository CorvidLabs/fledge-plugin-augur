# Changelog

## 1.0.0

- Track `CorvidLabs/augur` `1.0.0`.

## 0.3.0

- Track `CorvidLabs/augur` `0.4.1`.

## 0.1.0

- Initial release
- `fledge augur check`: assess a diff and print a verdict (human or `--json`)
- `fledge augur gate`: exit non-zero when the verdict meets a `--threshold`
- Links `AugurKit` directly (no external `augur` binary required)
